# Security Policy

## Reporting a Vulnerability

Se você encontrar uma vulnerabilidade, **não abra uma issue pública**.

Preferencialmente, use **GitHub Security Advisories**:

1. Vá em **Security** → **Report a vulnerability**.
2. Inclua o máximo de detalhes possível (abaixo).

Se essa opção não estiver disponível, entre em contato com o mantenedor por um canal privado (ex.: e-mail no perfil do GitHub).

### O que incluir

- Descrição e impacto (o que um atacante conseguiria fazer)
- Passos para reproduzir (PoC, entradas, payloads)
- Versão/commit afetado
- Logs/stack traces relevantes (se houver)
- Mitigação sugerida (se você tiver)

## Supported Versions

- Apenas a versão mais recente (branch `main`/último release) recebe correções de segurança.
